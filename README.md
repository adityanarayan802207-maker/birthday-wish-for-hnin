# A Little Birthday Surprise ♡

A dreamy Korean-inspired, mobile-friendly birthday website featuring:
- A surprise envelope entrance
- An interactive photo box with all five photos supplied in the chat
- English and Burmese birthday wishes
- A virtual cake with a blow-out candle interaction
- A cake-cutting animation, confetti, and a personal final message
- A synthesized Happy Birthday melody (no external song file required)
- Floating hearts and pastel floral styling

## Preview
Open `index.html` in a browser. Keep the `photos` folder beside it.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **new public repository** (for example, `birthday-surprise`).
2. Upload `index.html`, `README.md`, and the entire `photos` folder. Keep the folder name exactly `photos`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. After deployment, your site will be available at `https://YOUR-USERNAME.github.io/birthday-surprise/`.

## Personalize
Edit the wishes in `index.html`. Replace photos in `photos/` using the same filenames if needed.
The birthday melody starts only after she taps Play because mobile browsers block autoplay audio.
